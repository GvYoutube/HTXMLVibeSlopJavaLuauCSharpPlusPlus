A SPECIFICATION, SORT OF

Familiar ingredients.
Unfamiliar consequences.

01

Everything is a tag

Declarations, output, loops, and function calls all wear angle brackets. It’s markup! It’s code! It’s a syntax error waiting to happen!

02

Functions eat functions

Put tags in functions, calls in tags, and conditionals wherever the vibes feel right. The playground supports a small, well-behaved subset.

03

Types are decorative

Write type="String" for the comforting illusion of safety. Values are strings. The compiler is a rice cooker.

THE EXTREMELY SMALL RUNTIME

Test the vibes.

Edit the code, then run it. Your browser executes only the tiny tag-based subset—not arbitrary JavaScript. Probably the safest part of this whole language.
